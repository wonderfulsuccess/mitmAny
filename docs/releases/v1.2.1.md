# mitmAny v1.2.1

- A visible **Support** button in the desktop toolbar opens optional $1, $10 and $100 one-time support links. All application features remain free; there is no subscription or paid feature unlock.
- AI-first README with a network-detective illustration, an MCP workflow diagram and evidence-based API reverse-engineering examples.
- README in English, Simplified Chinese, Traditional Chinese, Japanese and Korean. Application UI remains English and Simplified Chinese.

## Download and validation

macOS universal (Apple Silicon / Intel) and Windows x64 ZIPs include licenses and all five README languages. Verify downloads using SHA256SUMS.txt. Windows requires WebView2; move the macOS application to Applications.

These builds are unsigned; macOS is not notarized. GitHub Actions runs frontend tests, Go tests/vet, macOS race tests and native builds before release. The support dialog was checked in a browser preview in English and Chinese, including a narrow viewport, keyboard dismissal and the three Stripe destinations. No actual payment was made. Full physical-device acceptance testing is not complete.
