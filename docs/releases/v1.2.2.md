# mitmAny v1.2.2

Start your first capture with less setup and clearer feedback.

- **Two-step setup:** install and trust the local CA certificate, then start capture with automatic system proxy configuration. Already trusted certificates are marked complete. You can dismiss setup and return from the toolbar at any time.
- **Always-visible CA status:** a red toolbar label highlights missing, untrusted or invalid certificates and check failures. Status refreshes when the app regains focus, after installation and before capture starts.
- **Helpful empty states:** see what to do before capture, while waiting for requests, when recording is paused, or when filters hide your requests. Resume recording or clear filters directly.
- **Capture troubleshooting:** persistent errors and a toolbar guide explain proxy routing, existing upstream proxies, port conflicts, app-specific HTTPS trust and desktop network recovery.
- English and Simplified Chinese UI, with an adapted toolbar for narrow desktop windows.

## Downloads

Choose the macOS universal ZIP (Apple Silicon / Intel) or Windows x64 ZIP. Archives include licenses and documentation. Verify downloads with `SHA256SUMS.txt`. Windows requires WebView2; move the macOS app to Applications.

## Validation and limitations

Frontend tests/build, Go race tests/vet, dependency license collection and secret scanning passed locally. GitHub Actions builds and tests both macOS and Windows before producing release assets. Setup, skipped/canceled installation, certificate failures, start failures, focus refresh, filtered results and responsive layouts were checked with synthetic desktop APIs in a browser. These UI checks do not change system trust or proxy settings. Full clean-machine CA authorization and physical-device acceptance across all platforms remain unverified.

Consult the signing-status files shipped with the downloads for platform signing and notarization status.
