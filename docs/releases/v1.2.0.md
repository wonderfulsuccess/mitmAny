# mitmAny v1.2.0

Desktop HTTP / HTTPS traffic inspection for macOS and Windows, with Android USB capture and a read-only MCP bridge.

- English by default, with a persistent Simplified Chinese language option.
- Bounded HTML capture and decompression, clearer truncation diagnostics, and safer HAR/legacy-body handling.
- First-capture guidance, network recovery controls, privacy notices, MIT licensing and bilingual documentation.
- Optional one-time project support links.

## Downloads

- macOS universal ZIP: Apple Silicon and Intel. Extract and move mitmAny.app to Applications.
- Windows x64 ZIP: extract before launch; requires Microsoft Edge WebView2 Runtime.
- SHA256SUMS.txt: SHA-256 checksums for both ZIPs.

Packages contain the application, licenses, documentation and SIGNING.txt. These are unsigned builds; macOS is not Developer ID signed or notarized, and Windows has no Authenticode signature. Follow your system's application approval flow only after verifying the source and checksum; do not disable system security globally.

Validation: automated frontend tests, Go tests and vet, macOS race tests, and native builds run in GitHub Actions. Physical Android-device and full Windows/macOS capture-and-recovery acceptance testing has not been completed for this release.
